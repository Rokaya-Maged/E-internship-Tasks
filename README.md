# 🚀 Network Automation Toolkit

A collection of Python-based tools developed during my internship at **e& Egypt**, focused on automating network operations, parsing raw device outputs, and improving efficiency in handling network data.

---

## 📌 Overview

This repository showcases practical implementations of **network automation concepts** using Python.
The goal is to reduce manual work, improve accuracy, and transform raw network data into structured, meaningful insights.

---

## 🛠️ Projects Included

### 🔹 Router Version Automation Tool

* Connects to network devices via SSH
* Extracts software and version information
* Generates structured Excel reports
* Highlights devices that require upgrades

---

### 🔹 Routing Table Analyzer

* Parses raw CLI outputs (`show ip route`)
* Uses regex to handle unstructured data
* Converts routing tables into clean, readable formats

---

### 🔹 GUI-Based Network Tool

* Simple interface built with Tkinter
* Allows easier interaction with automation scripts
* Combines backend logic with a user-friendly frontend

---

## ⚙️ Technologies Used

* **Python**
* **Paramiko** (SSH automation)
* **OpenPyXL** (Excel report generation)
* **Regex** (data parsing)
* **Tkinter** (GUI development)

---

## 📊 Features

* Automates repetitive network tasks
* Transforms raw CLI output into structured data
